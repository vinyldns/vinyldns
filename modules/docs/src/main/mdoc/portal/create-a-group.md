## Create a group
1. In the Groups area of the site select the *New Group* button. This will bring up a form.
1. Enter a name for the group, email address and an optional description. Use a single-word name, with hyphens instead of spaces.
   If *Valid Domains for Email* is displayed, expand it and use an email address in an allowed domain.
1. Select the *Create* button to submit the group information.
1. If all fields are valid you'll see the group listed in the table on the screen when the form closes.

You are automatically added as both a member and a group manager. Next, [manage membership](manage-membership.html)
or learn how to [edit the group and view its history](groups.html).
