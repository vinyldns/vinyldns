## Create a Group

1. In the Groups area of the site select the New Group button. This will bring up a form.
2. Enter a name for the group, email address and an optional description.
3. Select the Create button to submit the group information.
4. If all fields are valid you'll see the group listed in the table on the screen when the form closes.
