## Update Group Email

A group administrator can update the email address associated with a group. The group email is the distribution-list address used for group notifications.

1. Open **Groups** and find the group in **My Groups**.
2. Select **Edit** for that group. The Edit Group dialog displays the current group name, email, and description.
3. Replace the value in **Email** with the new distribution-list address. The name and description can also be updated if needed.
4. Select **Update Group** to save. The email field is required and must contain a valid email address.

[![Edit Group dialog with the email field](../img/new-portal/update-group.png){:.screenshot}](../img/new-portal/update-group.png)

If the update does not succeed, check that the address is valid and that you have permission to edit the group.
