# New Portal Guide

The VinylDNS new portal is the primary user interface for interacting with VinylDNS. Users can retrieve their credentials and manage zones, records, and user groups. This guide covers the functionality of the new portal.

## Navigating the New Portal

[![New portal navigation and user menu](../img/new-portal/navigation-portal.png){:.screenshot}](../img/new-portal/navigation-portal.png)

The new portal provides an improved user experience with enhanced features for managing DNS zones and records. The interface includes:

### Top Navigation Bar

- **Logo** - Links back to the home page
- **DNS Changes** - Access to bulk DNS change operations
- **Zones** - Zone management and record operations
- **Groups** - User group management
- **Portal Links** - Switch between old and new portal versions
- **User Menu** - Access to credentials and account options
- **Theme Toggle** - Switch between light and dark themes

### Left Sidebar

Quick navigation menu to access main features:

- **Groups** - View and manage user groups
- **Zones** - Manage DNS zones and records
- **DNS Changes** - Submit and track batch DNS changes
- **RecordSet Search** - Global search across all accessible records

### User Menu

The User Menu is located in the top right corner of the portal and accessed by selecting your username. It contains:

- **Download Credentials** - Export API credentials for external tools
- **Regenerate Credentials** - Create new credentials if existing ones are compromised
- **Logout** - Sign out of the portal

## Key Sections

### Zones

The Zones section of the portal is for managing DNS zones and records. This area also includes more granular management of user abilities. To access Zones select the Zones link in the navigation. Access to individual zones in this part of the portal is limited to zone administrators and users with explicit permissions.

[Learn More](zones.html)

### Groups

The Groups section of the portal is for managing high level user access and abilities. To access Groups select the Groups link in the navigation.

[Learn More](groups.html)

### DNS Changes

The DNS Changes section of the portal allows users to implement multiple record changes simultaneously and across different zones. To access DNS Changes select the DNS Changes link in the navigation.

[Learn More](dns-changes.html)

### Credentials

In order to use tooling to access VinylDNS, all users must download their credentials from the VinylDNS portal. The credentials are located in the User Menu in the top right corner of the site after login.

[Learn more](credentials.html)
